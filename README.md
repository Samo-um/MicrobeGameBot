# MICROBE 🦠
Мобильное веб-приложение MICROBE — игровая Telegram Mini App.

## Логика баланса
Старт: Баланс 0, Звёзды 0, Уровень 0, Подарки 0, Инвентарь 0.
Приз даёт столько, сколько стоит:
🦠 Микроб +3, 🎁 Подарок +5, ⭐ Звезда +5, 🧸 Мишка +10, 💖 Сердце +15, 💎 Кристалл +20, 🚀 Ракета +25, 👑 Корона +50
Пример: Мишка (10) + Корона (50) = Баланс 60
