# MICROBE 🦠
Мобильное веб-приложение MICROBE — игровая Telegram Mini App.

## Цвета
- Фон: #260D2B, Фиолетовый: #48134E / #722276, Розовый: #A832A1 / #D84BCB / #F18CE5
- Зелёный: #004D40 / #087B60 / #119C77 / #19C99A / #75DDBB / #A5F0D4
- Золото: #FFC02E / #FFE27A, Оранжевый: #FF9F24, Красный: #E64C42

## Структура
- index.html — разметка всех экранов
- css/style.css — все стили
- js/data.js — нулевые данные
- js/navigation.js — навигация
- js/app.js — логика
- js/animations.js — анимации, тосты

## Запуск
1. Залей в GitHub
2. Settings -> Pages -> Branch: main -> Save
3. Открой https://USERNAME.github.io/MICROBE/

## Важно
Все показатели начинаются с 0. Без сервера данные демонстрационные.
